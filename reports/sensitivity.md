# 感度分析：セッション閾値と D1 の秒数（本番サンプル）

- 実行日：2026-10-22
- 手順：`reports/evaluation_protocol.md` の8節。基準の結果は `reports/main_results.md`。
- 方法：本番サンプル（10,000人）で、次の4通りについて、手順をそのまま（推定・評価・生成のすべて）やり直した。変えたのは1つの値だけ。
  - セッション閾値：30分・120分（D1 は 0.5秒のまま）
  - D1 の秒数：0.2秒・1秒（閾値は60分のまま）
- 実行：`python src/evaluate.py --users data/processed/main_sample/manifest.json --out ... --gap-min <分> --auto-sec <秒>`

## 結論
**主な結論は、4通りのどれでも変わらなかった。**
- 決定点の Log Loss は、どの設定でも M3 < M2 < M1 < M0 の順。
- M3−M1 は −0.032〜−0.033 で、95%区間はどれも0を含まない。M3−M2（−0.011前後）、M2−M1（−0.021前後）も同じ。
- 正解率は、どの設定でも M1・M2・M3 でほぼ同じ（M3−M1 の区間は0を含む）。
- ECE は、どの設定でも M1 がもっとも低い。M3−M1 の差は、閾値30分のときだけ区間が0をわずかに含まなかった（+0.013、区間 +0.000〜+0.026）。ほかの設定では0を含む。
- 生成したセッションが実データの後半より長いという問題も、どの設定でも同じだった。

## 1. 評価の対象
| 設定 | 完了したセッションがある学習者 | D7 を満たす学習者 | 評価する決定点 | 評価する全イベント |
|---|---|---|---|---|
| 基準（60分・0.5秒） | 2,535 | 1,632 | 304,694 | 1,808,771 |
| 閾値30分 | 2,589 | 1,645 | 305,831 | 1,817,039 |
| 閾値120分 | 2,485 | 1,615 | 303,264 | 1,798,975 |
| D1 0.2秒 | 2,535 | 1,633 | 304,987 | 1,808,842 |
| D1 1秒 | 2,535 | 1,626 | 292,473 | 1,808,416 |

- 閾値を変えると、セッションの区切りが変わる。そのため、完了したセッション（D8）や評価対象の学習者も少し変わる。
- D1 の秒数は決定点の選び方だけを変える。全イベントの評価と生成は、評価対象の学習者がわずかに変わる以外は基準と同じ。

- 閾値を長くするほど、どのモデルも Log Loss が少し下がる（30分 0.588 → 120分 0.569、M3）。セッションが長くなり、予測の難しい「終了」が減るためと考えられる。
- D1 を1秒にすると、決定点が約12,000件減る。どのモデルも Log Loss が約0.02上がる（M3 0.600）。それでも、モデルの順位と差はほぼ同じ。
- M3−M2 の正解率の差は、どの設定でも +0.001 前後で、区間は0を含まない。ただし、大きさはごくわずか。

## 4. 再現性（生成）
| 設定 | 実データ後半の平均の長さ | M1 | M3 | 終了率 実 / M1 / M3 | 学習者別 Spearman（M3） |
|---|---|---|---|---|---|
| 基準 | 108.4 | 139.6 | 156.0 | 0.0092 / 0.0072 / 0.0064 | 0.28（1,384人） |
| 閾値30分 | 96.8 | 123.0 | 137.9 | 0.0103 / 0.0081 / 0.0072 | 0.31（1,406人） |
| 閾値120分 | 121.1 | 157.6 | 178.0 | 0.0083 / 0.0063 / 0.0056 | 0.27（1,353人） |

- どの閾値でも、生成したセッションは実データより約3割長い（M1）。終了率は実データより低い。
- 時間とともにセッションが短くなる変化をモデルが表せていない、という問題は、閾値の選び方によらない。
- D1 の秒数は生成に影響しない（決定点の定義だけに関わるため）。

## 解釈（推測を含む）
- 「学習者ごとの違いを入れると決定点での行動の確率の見積もりがよくなる（M3 が最良）」という主な結論は、セッション閾値（30〜120分）と自動表示の判定（0.2〜1秒）の選び方に依存しない。
- 「当たり外れは変わらない」「較正は M1 がもっともよい」「セッションの長さの再現が足りない」という限界も、同じように設定によらない。
- ECE の M3−M1 の差は、閾値30分でだけ区間が0をわずかに含まなかった。較正については、「M3 は M1 よりやや悪い傾向がある」と書くのが妥当。
